# taichi-dsh-official-doc

DSH Desktop 的公文插件。它从插件市场手动安装，不随桌面内置。

安装并激活后，活动栏出现「公文」。页面内包含工作台、文档处理、Markdown 优化、校审中心、模板中心和关于。

## 当前重构进度

商业化重构的阶段状态、最近测试结果、已知风险和新会话续作顺序记录在 [HANDOFF.md](HANDOFF.md)。续作前先阅读该文件；当前工作区含未提交改动，不要清理。

## 能力概览

| 模块 | 能力 |
|------|------|
| 工作台 | 文档/校审/问题/优化统计、快捷入口、最近文档跳转校审 |
| 文档处理 | 上传 `.docx`、选择文种、格式检查、A4 预览 |
| 校审中心 | 按严重度筛选、勾选修复下载、暗标扫描与脱敏、打印/导出 PDF、AI 深度分析（太极会话） |
| Markdown 优化 | 左右分栏 A4 预览、表格、下载 docx、润色/去 AI 味（太极会话） |
| 模板中心 | 22 文种目录、选用生成、规则编辑、从 docx 提取格式、会话起草 |

格式检查、docx 修复、暗标、Markdown 转换与模板生成由插件完成。文字润色、去 AI 味、深度分析与模板起草使用**太极当前会话**，不在插件里配置模型供应商。

## 边界说明（相对原桌面版）

- 仅接收 `.docx`；`.doc` / `.wps` 请先另存为 docx（不内嵌转换器）。
- PDF 通过浏览器「打印 → 另存为 PDF」，不依赖 LibreOffice。
- 不提供 Office/WPS 插件桥、局域网网页访问、多厂商 AI 设置页。
- 模板以规则 YAML + 示例 docx 为主，不打包重型 `.dotx`。
- 包体目标 ≤ 8 MiB。

## 开发

```bash
npm install
npm test
npm run build:client
```

发布前用 `npm pack --dry-run` 确认包内包含 `cordis.patch.yml`、`dsh/`、`lib/`、`rules/` 和 `templates/`，且不超过 8 MiB。

市场上架需另向 `awesome-dsh-plugin` 提交收录条目。收录合并不代表桌面市场已经可见。
